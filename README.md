# 🪑 Furniture Store Management System

A C# desktop application built to manage furniture inventory, customers, and orders through a clean and organized interface.

## ✨ Features
- Manage furniture inventory
- Add, update, and delete customer records
- Track customer orders
- User-friendly Windows Forms interface
- Multi-layered architecture (UI, Business Logic, Data Access)

## 🛠️ Technologies Used
- C#
- .NET
- Windows Forms
- Object-Oriented Programming (OOP)
- Layered Architecture (UI, BLL, DAL)

## 🎯 Purpose
This project was developed as part of a Computer Programming course to practice software engineering principles, object-oriented design, CRUD operations, and building maintainable applications.
